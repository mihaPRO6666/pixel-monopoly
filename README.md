# 🎩 Pixel Monopoly — Онлайн Монополия в стиле Material You

Красивая, чистая и лаконичная игра «Монополия» для игры с друзьями и ботами, созданная по канонам **Material Design 3 / Material You (Google Pixel)** с поддержкой синхронизации комнат в реальном времени через **Supabase Realtime** и мгновенным деплоем на **Vercel**.

---

## ✨ Особенности игры

- 🎨 **Стиль Material You (Google Pixel)**: 4 динамические темы оформления (*Mint*, *Coral*, *Ocean*, *Dusk Dark*), мягкие скругленные формы, отсутствие кислотного неона и лишних надписей.
- 🌐 **Мультиплеер через Supabase Realtime**: создание лобби, короткий код комнаты и ссылка-приглашение в 1 клик (`?room=CODE`).
- 🔄 **Авто-восстановление сессий (Reconnect)**: при случайном закрытии вкладки или обрыве связи можно мгновенно вернуться в игру на тот же ход.
- ⚡ **5 готовых шаблонов правил**:
  1. **Классика** — стандартные правила Монополии.
  2. **Быстрый блиц** — $2500 на старте, круг $400, раздача по 2 улицы каждому игроку.
  3. **Джекпот & Казна** — все налоги и штрафы идут в банк «Бесплатной стоянки».
  4. **Строительный бум** — стройка домов без сбора монополии, дома дешевле на 30%.
  5. **Хардкор** — $1000 на старте, удвоенные налоги, запрет ренты в тюрьме.
- 🔊 **Звуковой синтезатор**: Web Audio API с регулятором громкости и кнопкой Mute.
- 👤 **Мини-профиль и статистика**: выбор фишки, подсчет побед, поражений и процента побед.
- 🤖 **Умные AI-боты**: возможность добавить ботов в лобби для тренировки или дополнения компании.

## 🚀 Как задеплоить на Vercel (аккаунт `hizu1`)

Проект полностью оптимизирован для Vercel и содержит `vercel.json` и `package.json`.

### Вариант 1: Через GitHub и Vercel Dashboard (Самый простой)
1. Создайте новый репозиторий на [GitHub](https://github.com) и загрузите файлы из этой папки.
2. Перейдите в панель управления Vercel: **[https://vercel.com/hizu1](https://vercel.com/hizu1)**.
3. Нажмите кнопку **«Add New...» ➔ «Project»**.
4. Выберите ваш GitHub-репозиторий и нажмите **«Deploy»**.
5. Через 10 секунд ваша Монополия будет доступна по персональному адресу вида `https://pixel-monopoly-hizu1.vercel.app`!

### Вариант 2: Локальный запуск
Для тестирования на компьютере достаточно выполнить в терминале:
```bash
python -m http.server 3000
```
И открыть в браузере: `http://localhost:3000`.
